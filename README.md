# Full Stack Development

A structured learning repository for modern web development, from core browser technologies to frontend frameworks, backend services, databases, tooling, and deployment.

## Suggested learning order

1. HTML and CSS fundamentals
2. JavaScript, TypeScript, browser APIs, and accessibility
3. Git, GitHub, and collaborative workflows
4. React and other frontend frameworks
5. Node.js, APIs, databases, testing, and deployment

## Repository layout

Learning materials are organized under `Prayag Gaikwad/`. Follow the folder and filename conventions already used within each topic, and keep examples small enough to run and understand independently.

## Contributing to your own notes

- Use descriptive filenames and keep examples focused on one concept.
- Include setup/run instructions when a project needs dependencies.
- Do not commit `.env` files, tokens, passwords, or private data; use `.env.example` for non-secret configuration templates.
- Treat third-party examples and downloaded code according to their licenses.

## Status

This repository is a learning archive, not a claim that every example is production-ready. Test runnable examples with their documented toolchain.
