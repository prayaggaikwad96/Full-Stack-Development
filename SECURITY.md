# Security Policy

## Supported versions

The default branch, `main`, is the maintained version of this learning repository. Archived branches and old snapshots are retained for history and recovery; they are not guaranteed to receive security fixes.

## Reporting a vulnerability

Please **do not** publish credentials, tokens, exploit details, private data, or a working exploit in a public issue or pull request.

For a sensitive report, use GitHub's **Report a vulnerability** option under the repository's **Security** tab if private vulnerability reporting is available. If that option is unavailable, contact the repository owner through the GitHub profile and request a private disclosure route.

A useful report includes the affected path or component, the impact, reproducible steps that do not expose real data, and a suggested mitigation when known. Please allow reasonable time for investigation and remediation. This project does not promise a fixed response-time SLA.

Do not test against systems or data you do not own or have explicit permission to assess.
