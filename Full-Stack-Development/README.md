📁 Repository Layout
Learning materials are organized under:
Prayag Gaikwad/
└── Prayag Gaikwad CSS/
    └── Projects/

The repository contains learning materials, exercises, projects, and examples organized by topic and difficulty.
Follow the folder and filename conventions already established within each topic. Keep individual examples focused and small enough to run, understand, and modify independently.
🛠️ Working With Projects
When adding a project or example:

Use a descriptive filename and folder name.
Keep each example focused on a specific concept.
Include setup and run instructions when dependencies are required.
Keep related files together.
Avoid unnecessary generated files and build artifacts.
Update the relevant documentation when the structure of a project changes.

🔐 Security
Never commit sensitive information to this repository.
Do not commit:

.env files containing secrets
API keys
Access tokens
Passwords
Private credentials
Personal or confidential data

Use .env.example for configuration templates without real secrets.
📜 Licenses & Third-Party Code
Respect the licenses of third-party examples, libraries, tutorials, and downloaded code.
When using external code:

Check its license before committing it.
Preserve required copyright and license notices.
Clearly distinguish your own work from third-party material.

📌 Repository Status
This repository is primarily a learning archive and development workspace.
Not every example is intended to be production-ready. Runnable examples should be tested with their documented toolchain, dependencies, and configuration.
The repository will evolve as new technologies, concepts, projects, and experiments are added.
