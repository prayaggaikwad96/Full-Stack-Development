CSS SPECIFICITY

Complete Learning Notes | Beginner to Advanced

1. What is CSS Specificity?

CSS Specificity determines which CSS selector wins when multiple CSS rules target the same HTML element.

Example

p {
    color: blue;
}

.text {
    color: green;
}

#demo {
    color: red;
}
Explanation: The ID selector has higher specificity than the class and element selectors.

Hello World - Final Output is RED

2. CSS Specificity Formula

CSS specificity is represented using four columns:

A - B - C - D

Level Selector Type Example Specificity
A Inline Styles style="color:red" 1-0-0-0
B ID Selectors #header 0-1-0-0
C Classes, Attributes, Pseudo-classes .box, [type], :hover 0-0-1-0
D Elements, Pseudo-elements div, ::before 0-0-0-1

Understanding Each Level

A - Inline Styles

<p style="color: red;">Hello</p>

Specificity: 1-0-0-0

B - ID Selectors

#header {
    color: red;
}

Specificity: 0-1-0-0

C - Class Selectors

.box {
    color: red;
}

Specificity: 0-0-1-0

D - Element Selectors

p {
    color: red;
}

Specificity: 0-0-0-1

5. How to Calculate Combined Selectors

Example 1

.container .box p {
    color: red;
}

Calculation:

  • .container = 0-0-1-0
  • .box = 0-0-1-0
  • p = 0-0-0-1
Total = 0-0-2-1

Example 2

#main .container .box p {
    color: red;
}

Calculation:

  • #main = 0-1-0-0
  • .container = 0-0-1-0
  • .box = 0-0-1-0
  • p = 0-0-0-1
Total = 0-1-2-1

Example 3

#header #main .box {
    color: red;
}

Calculation:

  • #header = 0-1-0-0
  • #main = 0-1-0-0
  • .box = 0-0-1-0
Total = 0-2-1-0

7. Important Special Selectors

Selector Specificity
:hover 0-0-1-0
:focus 0-0-1-0
:active 0-0-1-0
::before 0-0-0-1
::after 0-0-0-1
:not() Specificity of its argument
:is() Most specific argument
:where() Always 0-0-0-0

Example of :not()

p:not(.active) {
    color: red;
}

Calculation:

  • p = 0-0-0-1
  • .active = 0-0-1-0
Total = 0-0-1-1

Example of :where()

:where(#header .box) {
    color: red;
}
Specificity = 0-0-0-0
Even though it contains an ID and a class, :where() contributes zero specificity.

8. What is !important?

!important is NOT a specificity value. It changes the cascade priority of a CSS declaration.

Example

p {
    color: blue !important;
}

#demo {
    color: red;
}
Result: BLUE
Assuming both declarations have the same cascade origin and layer, the important declaration wins.

Important: Avoid using !important unnecessarily.

9. What Happens When Specificity Is Equal?

When two applicable selectors have equal specificity, the later declaration wins if their cascade origin, importance and layer are the same.

Example

.text {
    color: blue;
}

.text {
    color: red;
}

Both selectors have specificity:

0-0-1-0

Final Output: RED

Reason: The second declaration comes later.

10. Important CSS Specificity Rules

  • Specificity is compared from left to right.
  • Never add all specificity digits into one number.
  • An ID selector beats any number of class selectors.
  • A class selector beats any number of element selectors.
  • If specificity is equal, source order can determine the winner.
  • !important changes cascade priority, not specificity.
  • Universal selector * has zero specificity.
  • :where() always has zero specificity.
  • :not() and :is() use the specificity of their arguments.
  • Inline styles have specificity 1-0-0-0.

11. CSS Specificity Interview Questions

Q1. Which selector has higher specificity? 
.box
#box
div

Answer: #box

Q2. What is the specificity of this selector? 
.container .box p

Answer: 0-0-2-1

Q3. Can 10 classes beat one ID?

Answer: NO.

An ID has a higher priority column than classes.
Q4. What is the specificity of the universal selector?

Answer: 0-0-0-0

Q5. What is the specificity of :where()?

Answer: 0-0-0-0

Q6. What happens if two selectors have equal specificity?

Answer: The later applicable declaration wins when the other cascade conditions are equal.

Q7. Is !important part of specificity?

Answer: NO.

It changes cascade priority.
