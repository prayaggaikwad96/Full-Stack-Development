The list-style-position Property

Explore interactive beverage cards demonstrating CSS list styling with smooth hover effects.

Quick Key Difference:

  • outside (default): The bullet point hangs outside the flow of the list item's text block.
  • inside: The bullet point is placed inside the content flow, meaning wrapped text flows underneath the bullet.

list-style-position: outside (default)
