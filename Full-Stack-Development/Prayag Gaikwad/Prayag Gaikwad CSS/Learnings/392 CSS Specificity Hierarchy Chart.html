CSS SPECIFICITY – COMPLETE LEARNING NOTES 1. What is CSS Specificity? CSS Specificity determines which CSS selector wins when multiple CSS rules target the same HTML element. Example: css p { color: blue; } .text { color: green; } #demo { color: red; } The final output will be RED because the ID selector has higher specificity. 2. Important Special Selectors Selector Specificity :hover 0-0-1-0 :focus 0-0-1-0 :active 0-0-1-0 ::before 0-0-0-1 ::after 0-0-0-1 :not() Takes specificity of its argument :is() Takes specificity of its most specific argument :where() Always 0-0-0-0 Example of :not() css p:not(.active) { color: red; } Specificity: p = 0-0-0-1 .active = 0-0-1-0 Total = 0-0-1-1 Example of :where() css :where(#header .box) { color: red; } Specificity = 0-0-0-0 Even though it contains an ID and a class, :where() contributes zero specificity. 8. What is !important? !important is NOT a specificity value. It changes the cascade priority of a CSS declaration. Example: css p { color: blue !important; } #demo { color: red; } The blue declaration wins because it is marked !important, assuming both declarations have the same cascade origin and layer. Important: Avoid using !important unnecessarily. 9. What Happens When Specificity Is Equal? When two applicable selectors have equal specificity, the later declaration wins if they have the same cascade origin, importance and layer. Example: css .text { color: blue; } .text { color: red; } Both selectors have specificity: 0-0-1-0 Final Output: RED Reason: The second declaration comes later. 10. Important CSS Specificity Rules Specificity is compared from left to right. Never add all specificity digits into one number. An ID selector beats any number of class selectors. A class selector beats any number of element selectors. If specificity is equal, source order can determine the winner. !important changes cascade priority, not specificity. Universal selector * has zero specificity. :where() always has zero specificity. :not() and :is() use the specificity of their arguments. Inline styles have specificity 1-0-0-0. 11. CSS Specificity Interview Questions Q1. Which selector has higher specificity? css .box #box div Answer: #box Q2. What is the specificity of this selector? css .container .box p Answer: 0-0-2-1 Q3. Can 10 classes beat one ID? Answer: NO. An ID has a higher priority column than classes. Q4. What is the specificity of the universal selector? Answer: 0-0-0-0 Q5. What is the specificity of :where()? Answer: 0-0-0-0 Q6. What happens if two selectors have equal specificity? Answer: The later applicable declaration wins when the other cascade conditions are equal. Q7. Is !important part of specificity? Answer: NO. It changes cascade priority. 12.
