HTML Absolute and Relative URLs

Absolute URLs

Absolute URLs contain the complete address of another website.

Google

YouTube

GitHub

Relative URLs

Relative URLs link to pages inside the same website or project.

About Page

Contact Page

Services Page

Difference

Absolute URL: Uses the complete website address.

Example: https://www.google.com/

Relative URL: Uses the location of a file inside the current website.

Example: about.html
